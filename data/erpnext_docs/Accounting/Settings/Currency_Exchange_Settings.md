# Currency Exchange Settings

[Open in Claude

ERPNext comes with 2 predefined configuration for Currency Exchange Rate providers: [Frankfurter.dev](https://www.frankfurter.dev) and [Exchangerate.host](http://Exchangerate.host)

# [Frankfurter.dev](https://www.frankfurter.dev)

This is a free exchange rate provider that provides exchange rates for a limited set of currencies.
