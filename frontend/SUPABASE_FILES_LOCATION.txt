  12. ecommerce_metrics

How to use:
  1. Open this file in your text editor
  2. Select all (Ctrl+A or Cmd+A)
  3. Copy (Ctrl+C or Cmd+C)
  4. Go to https://supabase.com → Your Project → SQL Editor
  5. Click "New Query"
  6. Paste (Ctrl+V or Cmd+V)
  7. Click "Run"

================================================================================
EMERGENCY TROUBLESHOOTING
================================================================================

Issue: "Supabase credentials not found"
Fix: Check .env.local exists, has correct format, restart dev server

Issue: "Connection refused"
Fix: Verify credentials in .env.local, check Supabase project is running

Issue: "Table does not exist"
Fix: Run schema.sql in Supabase SQL Editor, verify tables were created

Issue: Data not appearing
Fix: Check tables have data in Supabase, check browser console for errors
